## 🎯 今日核心目標
- [x] 讓 Artisan 的烘焙屬性能自動帶上當下的環境天氣(氣溫/氣壓/濕度)

## 📝 隨手筆記 / 今日心得
- 今天整天和 AI(Claude)一起 cowork,把「Artisan 自動記錄環境天氣」從研究做到上線。
- 本來想直接在 Trident 韌體裡上網抓 Open-Meteo,結果一燒進去 **WebSerial 就當掉**。一起排查才挖出真因:ESP32 同時跑 BLE + WiFi + 螢幕 + WebServer,內部記憶體只剩 ~17KB,根本做不了 HTTPS 的 TLS 握手(要 16–40KB),還會把整個 web server 一起餓死。這段用序列埠抓 heap 數據把真相抓出來,蠻過癮的——原來之前的「抓取失敗」不是網路不穩,是記憶體不夠。
- 於是換架構:**HTTPS 交給 PC 上一支小 proxy 做,Trident 只用純 HTTP 拉**,記憶體問題直接消失。又順手加了 **mDNS 自動探索**,連 PC 的 IP 都不用手填,換網路也能自己接回來。
- 最後整條驗證通了:Artisan 烘焙屬性有值、Trident 螢幕也顯示、WebSerial 也不當了。
- 收尾做了不少雜事:weather-proxy 做成獨立 git repo 推上 GitHub(還設 public)、寫了 README;Trident 的 branch 也推上自己的 fork;又在作品集部落格新增了 weather-proxy 和 Trident 兩個專案頁。
- 心得:遇到怪 bug 不要急著改碼,先**量測**。今天要不是去看 heap,大概會一直以為是網路問題繞遠路。
